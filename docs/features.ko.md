# 기능

- [o] M1 — P1: manifest가 moai 메이커 group을 선언해요. `plugin.json`은 plugin `agents`를 `dependencies`에 적고, extension point `agents.makers`에 item 하나를 기여해요. item의 `module`은 M5의 group module이에요. 입력: manifest. 기대: `dependencies`는 `{ "agents": "^0.0.1" }`, `contributes`는 `{ "agents.makers": [{ "range": "^0.0.1", "module": "ui/makers/moai.js" }] }`이고, 다른 field는 없어요. 진행: `test/manifest.test.mjs`가 manifest가 없는 상태에서 실패한 뒤(Red), 5/5 통과해요(Green). Range는 임시값이에요. 아직 어떤 repository도 extension point `agents.makers`의 version이나 item schema를 선언하지 않아서, `agents` release가 선언하면 `^0.0.1`을 바꿔요. module 파일은 M5예요.
- [ ] M2 — P1: 설치 때 moai plugin 폴더를 교정해요. 입력: `moai`의 release(`--plugin-dir` 원본). 기대: 설치된 `<plugin data>/plugin/`에서 hook 등록은 `${CLAUDE_PLUGIN_ROOT}` 기준 `hooks/hooks.json`으로 옮겨지고, 계정 설정은 계정 `settings.json`으로 옮겨지며, 프로젝트에는 `.moai/`만 시드되고, `moai:moai:` 이중 이름은 없어요(club.md, 측정 M1–M4). 기다리는 것: 프로젝트 `settings.local.json`을 `.moai/` 아래에 쓰는 `min-0-max/moai-adk` fork의 release예요. 그 쓰기를 fork 없이는 설치 교정으로 없앨 수 없어요.
- [o] M3 — P1: surface가 moai web document region을 선언해요. `plugin.json`은 최상위 `mark`와 `icon`, 그리고 `surface` composition을 선언해요. composition은 page `ui/web.html`의 `view`이고, document region `moai-web`(`input` `native`) 하나를 가져요. overlay는 없어요. page는 `data-region="moai-web"` element를 가지고 script는 없어요. 진행: `test/surface.test.mjs`가 surface가 없을 때 실패한 뒤(Red), plugin의 test 10개가 모두 통과해요(Green). `test/manifest.test.mjs`의 field 목록에 `mark`, `icon`, `surface`를 같은 변경에서 더했어요. surface가 그 field를 추가하기 때문이에요. Region에는 overlay가 없고 page는 script를 불러오지 않아요. Controller는 M4가 써요.
- [!] M4 — P1: moai web surface가 region에 `moai web`을 보여 주고, agent마다 port를 하나씩 쓰며, claude만 받아요. 보류: M5 group object가 없어서 page가 agent port를 불러오지 못해요. 원인: agent의 port는 group object(M5)에서 와요. 그 agent 목록과 port 번호는 moai release가 정해요(M5 원인). 재개 조건: M5가 재개될 때예요.
- [!] M5 — P1: group module `ui/makers/moai.js`가 moai group을 `agents.makers`에 기여해요. 보류: `group()`이 스키마에 맞는 객체를 아직 돌려주지 못해요. 원인: `makers.md`(agents A9)는 `agents`(name, path, cli, 웹 페이지를 주는 agent는 port), `skills`, `plugin`, `variables`, `path`, `folders`, `rules`를 요구하고, moai 저장소는 그 값을 하나도 갖지 않아요. Agent 이름(upstream `.claude/agents/moai/`에 12개 파일), 스킬(club.md는 moai 스킬 20개라고 적고, upstream은 `.claude/skills/`에 `moai*` 폴더 38개, `.agents/skills/`에 17개를 가져요), port 번호는 여기서 확인할 근거가 없어요. M2가 가져올 moai release가 이것을 정해요. 재개 조건: M2가 재개되어 release가 agent 목록, 스킬 목록, port를 정하거나, plugin 소유자가 이것을 정할 때예요.
- [o] M6 — P1, M1의 후속: moai 기여 item을 agents가 선언한 point에 맞춰요. 기여는 version `0.1.0`의 `agents.makers`(agents A7)에 맞춰 `id` `moai`, `name` `moai`, `range` `^0.1.0`을 가져요. 진행: `test/manifest.test.mjs`가 이전 item(`range` `^0.0.1`, `id`와 `name` 없음)에서 실패한 뒤(Red), 10/10 통과해요(Green). M1은 완료 상태라서 바꾸지 않아요.
- [o] M7 — P1, M6의 후속: 기여 range를 `^0.0.1`로 바꿔요. agents가 작업 트리에서 선언한 point version `0.0.1`을 포함해요. M6은 agents commit이 정정 전에 쓴 version으로 `^0.1.0`을 썼어요. 그래서 M6은 바꾸지 않아요. 진행: `test/manifest.test.mjs`가 `^0.0.1`을 기대하고 `^0.1.0`에서 실패한 뒤(Red), 10/10 통과해요(Green).
