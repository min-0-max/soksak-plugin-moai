- [!] M4 — P1: The moai web surface shows `moai web` in its region, with the port of the launch and claude only. Held: the plugin cannot start `moai web --port <free port>` and read the port it reports. Cause: (1) no contract gives a plugin a process it starts with an OS-chosen port: `core.layout.open` runs a program with its arguments but takes no port, a page cannot bind a TCP port, and starting a process for a plugin belongs to a sidecar of its own repository, which the plugin does not declare; (2) `moai web --port 0` does not report its bound port (`internal/cli/web.go` prints the requested `webPort`), so the port must be chosen before the start. Retry when: the core or the sidecar contract provides a launch that returns the port it bound, and the owner decides whether a moai sidecar lives in its own repository.
